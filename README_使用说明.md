# TRACEROOT 禾溯独立站源码

这是已发布网站的完整静态源码，包含最新联系电话 +86 137 5755 4679。

## 文件说明

- index.html：页面结构、俄语文案与联系方式。
- style.css：整体视觉、响应式布局、手机端适配和动效。
- app.js：中文文案、语言切换、产品切换、询价文本生成与复制/下载。
- assets/：网站使用的图片、Logo、图标和9页PDF宣传册。
- SHA256SUMS.json：各文件的校验值。

## 本地查看

解压后可直接用浏览器打开 index.html 查看页面。
推荐使用本地HTTP服务，以便更一致地使用浏览器功能：

1. 电脑安装 Python 3。
2. 在解压后的 TRACEROOT 文件夹中打开终端。
3. 执行：python -m http.server 8080 --bind 127.0.0.1
   Windows 也可以用：py -m http.server 8080 --bind 127.0.0.1
4. 浏览器打开 http://localhost:8080
5. 按 Ctrl+C 停止。

## 部署

这是原生 HTML、CSS、JavaScript 网站，无需安装依赖、编译或数据库。
将 index.html、style.css、app.js 和 assets 文件夹上传到静态网站托管服务或服务器的网站根目录，保持相对路径不变。建议启用 HTTPS，复制到剪贴板等浏览器功能需要安全上下文；不支持时页面会改为选中文本供手动复制。

## 修改内容

- 俄语默认文案：修改 index.html。
- 中文文案：修改 app.js 顶部的 zh 对象。
- 产品描述：修改 app.js 的 products 对象。
- 联系电话：修改 index.html 中的显示号码与 tel: 链接。
- 图片和PDF：替换 assets 中对应文件，保留文件名即可。

## 当前功能范围

- 默认俄语，支持中文切换；语言偏好保存在浏览器本地。
- 产品类别展示与选择。
- 支持点击电话号码拨号。
- 询价表单仅在浏览器内生成文本，支持复制和保存 TXT；不会发送邮件或自动提交订单，无收件后端。

- 源码包包含公开页面运行所需的全部内容，不含托管账号、访问密钥或 Git 历史；重新部署时由所选托管服务设置访问权限，页面源码本身不提供登录鉴权。
